# Assembly Programming

A focused collection of Assembly Language examples and coursework for the **Assembly Language 3F** unit. The repository is intended as a practical space for exploring low-level programming concepts, program structure, registers, memory, and instruction-level control flow.

## Overview

Assembly language provides direct exposure to how programs interact with processor architecture. This project supports hands-on learning through small, readable examples that can be adapted for class exercises and independent practice.

## Topics

- Assembly program structure and syntax
- Registers, memory, and data movement
- Arithmetic and logical instructions
- Branching, loops, and control flow
- Procedures and stack fundamentals
- Debugging and simulation workflows

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/eyesonnesta/assembly_programming_f.git
   cd assembly_programming_f
   ```

2. Install or open the assembler and simulator recommended for the course.

3. Review the examples and accompanying class materials before building or modifying a program.

## Project Structure

As the project grows, source files and supporting materials should be organised by topic or exercise. Keep filenames descriptive and group related examples together to make revision straightforward.

## Usage

Build and run each program with the assembler or simulator specified in your course instructions. Tooling and commands may differ by target architecture and environment.
